Tools

Online Tools I Actually Use

这些不是顺手做的小网页，而是 personal operating system 的可见切片。它们直接体现了我如何把复杂现实抽象成模型、状态和交互。

Tool 01

Money Simulator

用于做当前资产、未来收入和预算支出的情景模拟，把“生活决策”变成可以调整和观察的系统。

Why I built it: 我希望个人财务不是碎片化表格，而是一个能推演未来的模型。
Tool 02

Device / Subscription Tracker

用于记录实体资产、订阅、租赁、打卡和日历式使用成本，让物理世界里的持有与消耗都能进入同一账本。

Why I built it: 我想把“我拥有什么、花了多少、用了多久”统一到一个长期可维护的界面里。
Tool 03

Annual Tax Refund Planner

逐笔保存年度综合所得、预缴税额与扣除项目，区分已发生和预计收入，实时估算年度退税或补税。

Why I built it: 我希望把个税 APP 的零散申报记录和未来收入预测放进同一条可核对的年度计算链。
